## 한 줄 요약
터미널 환경에서 손을 떼지 않고 다양한 LLM API의 응답을 빠르게 테스트하고 비교할 수 있는 미니멀 CLI 도구입니다.

## 이게 뭔가요?
'ㅁㄴㅇㅇ(mnoo)'는 개발 중 웹 브라우저나 무거운 플레이그라운드를 띄울 필요 없이, 터미널 환경에서 바로 프롬프트 템플릿을 실행하고 모델별 출력을 비교할 수 있도록 설계된 오픈소스 CLI 유틸리티입니다.

복잡한 오케스트레이션 프레임워크와 달리 단일 바이너리로 동작하며, 로컬 환경 변수에 등록된 API 키를 기반으로 OpenAI, Anthropic, 로컬 Ollama 모델 등에 즉시 요청을 보냅니다. 마크다운 기반의 프롬프트 템플릿과 변수 매핑을 기본 지원해 스크립트 작성 시간을 줄여줍니다.

## 이렇게 활용해보세요
- **CI/CD 내 프롬프트 회귀 테스트**: 커밋 전 프롬프트 수정으로 인해 출력 포맷(JSON 등)이 깨지지 않는지 간단한 검증 스크립트로 자동화합니다.
- **파이프라인 데이터 가공**: `cat data.txt | mnoo run "핵심 요약"` 형태로 Unix 파이프라인에 결합해 텍스트 전처리 작업을 빠르게 처리합니다.
- **모델 간 응답 비교**: 동일한 프롬프트에 대해 여러 경량 모델의 레이턴시와 토큰 소모량을 터미널 테이블 형태로 한눈에 점검합니다.

## 주의할 점
- **복잡한 에이전트 미지원**: 도구 호출(Tool calling)이나 다단계 추론 체인 같은 복잡한 워크플로우 대신 단일 입출력 테스트에 초점이 맞춰져 있습니다.
- **API 비용 관리**: 터미널 기반으로 손쉽게 호출할 수 있는 만큼, 반복문이나 대량 데이터 처리 시 불필요한 API 호출 비용이 발생하지 않도록 토큰 제한 옵션을 확인해야 합니다.

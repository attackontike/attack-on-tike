## 한 줄 요약
n8n은 데이터 주권을 유지하면서 API와 AI 모델을 유연하게 결합할 수 있는 오픈소스 기반 워크플로우 자동화 도구입니다.

## 이게 뭔가요?
n8n은 Zapier나 Make처럼 여러 서비스 간의 작업을 자동으로 연결해 주는 노코드/로우코드 자동화 플랫폼입니다. 

기존 SaaS 기반 자동화 툴과 비교했을 때 가장 큰 차별점은 **직접 호스팅(Self-hosting)이 가능하다**는 점입니다. 사내 서버나 클라우드 인스턴스에 직접 설치해 사용할 수 있어, 데이터 외부 유출 위험이 적고 실행 횟수 기반 과금 압박에서 상대적으로 자유롭습니다. 

또한 LangChain 기반의 고급 AI 노드를 기본 지원하여, LLM, 벡터 데이터베이스, 사내 API를 드래그 앤 드롭 방식으로 손쉽게 엮을 수 있습니다.

## 이렇게 활용해보세요

1. **사내 지식 기반 AI 챗봇 및 고객 응대 자동화**
   - 웹훅(Webhook)으로 수신된 고객 문의를 n8n 워크플로우로 전달합니다.
   - 사내 벡터 DB(예: Pinecone, Qdrant)에서 관련 문서를 검색(RAG)한 뒤, LLM 노드를 거쳐 자연스러운 답변을 생성합니다.
   - 최종 답변을 슬랙, 이메일, 혹은 티켓팅 시스템으로 자동 회신합니다.

2. **반복적인 리포트 생성 및 요약**
   - 매일 아침 구글 애널리틱스, 결제 DB, 광고 관리자에서 데이터를 수집합니다.
   - n8n의 Code 노드(JavaScript/Python)로 데이터를 정제한 뒤, LLM에 프롬프트로 전달해 핵심 인사이트를 3줄 요약합니다.
   - 완성된 일일 리포트를 팀 슬랙 채널로 자동 발송합니다.

3. **다양한 LLM 간 성능 및 비용 벤치마크 파이프라인**
   - 동일한 입력 데이터를 OpenAI, Anthropic, 오픈소스 로컬 LLM(Ollama 연동)에 동시에 전달하도록 분기 노드를 구성합니다.
   - 각 모델의 응답 속도, 답변 품질, 토큰 비용을 구글 스프레드시트에 기록해 객관적인 비교 데이터를 축적합니다.

## 주의할 점

- **운영 및 인프라 관리 비용**: 셀프 호스팅을 선택할 경우 서버 유지보수, 도커(Docker) 컨테이너 관리, 워크플로우 실행 로그 축적으로 인한 DB 용량 최적화 등을 직접 챙겨야 합니다.
- **라이선스 정책 확인**: n8n은 'Sustainable Use License' 기반의 소스 공개 소프트웨어입니다. 내부 업무 자동화는 무료로 가능하지만, n8n 자체를 기반으로 타인에게 상용 서비스를 제공하는 것에는 제약이 있습니다.
- **복잡한 로직에서의 코드 의존도**: 노코드 인터페이스를 표방하지만, 데이터 구조가 복잡해지거나 커스텀 예외 처리가 필요할 때는 JSON 파싱 및 JavaScript 코딩 역량이 필수로 요구됩니다.

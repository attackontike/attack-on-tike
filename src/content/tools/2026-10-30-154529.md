## 한 줄 요약
주요 AI 뉴스를 RSS로 수집해 OpenAI API로 3줄 요약한 뒤, 슬랙이나 텔레그램으로 매일 아침 받아보는 노코드 자동화 파이프라인 구축법입니다.

## 이게 뭔가요?
쏟아지는 AI 뉴스를 일일이 찾아 읽는 대신, 노코드 툴인 **Make.com**(구 Integromat)을 활용해 **[수집 → 요약 → 발송]** 전 과정을 자동화하는 시스템입니다.

복잡한 백엔드 서버나 코딩 없이 드래그 앤 드롭 방식으로 모듈을 연결할 수 있습니다. 무료 플랜만으로도 개인 업무용 모니터링 시스템을 충분히 운영할 수 있어 시간 비용을 크게 줄여줍니다.

## 이렇게 활용해보세요

1. **트리거 설정 (RSS Feed 수집)**
   - Make.com 시나리오에서 `RSS` 모듈의 **Watch RSS feed items**를 추가합니다.
   - 모니터링할 AI 뉴스레터나 기술 블로그(예: TechCrunch AI, OpenAI 블로그 등)의 RSS URL을 등록합니다.
   - 스케줄 주기는 매일 아침 1회(예: 오전 8시)로 설정합니다.

2. **요약 처리 (OpenAI 모듈 연결)**
   - `OpenAI` 모듈의 **Create a Completion / Chat**을 연결합니다.
   - 비용 효율이 뛰어난 `gpt-4o-mini` 모델을 선택합니다.
   - 프롬프트에 RSS 본문(`Description` 또는 `Content`) 변수를 넣고 다음과 같이 시스템 지시어를 작성합니다:
     > "다음 AI 뉴스 기사를 바탕으로, 핵심 내용 3줄 요약과 업계 영향도 1문장을 한국어로 작성해줘. 원문에 없는 내용은 추측하지 마."

3. **알림 전송 (Slack / Telegram / Email)**
   - `Slack` 또는 `Telegram` 모듈을 마지막에 연결합니다.
   - 메시지 템플릿에 **[기사 제목]**, **[AI 요약 내용]**, **[원문 링크]**를 매핑해 전송합니다.

## 주의할 점

- **오퍼레이션(Operation) 한도 관리**: Make.com 무료 플랜은 월 1,000건의 오퍼레이션을 제공합니다. 실행 주기를 너무 짧게(예: 1분 단위) 잡으면 RSS 확인만으로도 크레딧이 소진되므로, 하루 1~2회 정기 실행으로 제한하는 것이 안전합니다.
- **입력 토큰 제한**: RSS 피드 중 본문 전체가 매우 긴 기사가 들어오면 API 비용이 급증하거나 에러가 날 수 있습니다. Make.com의 내장 함수인 `substring`을 활용해 본문 텍스트를 앞 2,000자 이내로 잘라 OpenAI 모듈로 넘기는 전처리를 권장합니다.
- **할루시네이션(환각) 제어**: 최신 기술 용어나 수치가 왜곡되지 않도록 프롬프트의 Temperature 값을 `0.2~0.3` 수준으로 낮춰 사실 기반 요약만 생성하도록 설정하세요.

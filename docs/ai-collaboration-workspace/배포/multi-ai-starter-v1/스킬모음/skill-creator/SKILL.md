# 워크스페이스 스킬크리에이터

로컬 스킬의 원본은 워크스페이스 최상위의 `스킬모음/`에서 관리한다. 환경 기본 스킬과 이름이 같으므로 이 파일의 실제 경로로 구분한다.

작업 전에 최상위 `law.md`와 [워크스페이스 생성·수정 절차](references/workspace-workflow.md)를 읽고 따른다. 기본 생성 위치, 탐색, 중복 처리, 의존성, 검증, 비교 HTML, 자동 목록의 한계는 이 절차에서 관리한다.

1. 로컬 폴더와 환경 스킬 목록을 모두 탐색하고 요청이 생성·수정·활용 중 무엇인지 판단한다.
2. 대화의 요구사항을 반영해 기본적으로 `스킬모음/<name>/SKILL.md`에 작성한다. 기존 폴더를 덮어쓰지 않는다.
3. [로컬 실행 도구](scripts/workspace-skills.mjs)로 목록과 구조를 검사하고 실제 요청에 맞는 동작을 점검한다. Python이나 Claude 전용 도구가 있다고 가정하지 않는다.
4. 최종 파일을 재탐색하고, 변경 전후 비교 HTML 및 검증 범위를 함께 제공한다.

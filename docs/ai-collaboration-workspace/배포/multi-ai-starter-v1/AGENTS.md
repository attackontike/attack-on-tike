# AGENTS.md

이 파일이 있는 프로젝트 루트의 [law.md](law.md)를 먼저 읽고 적용합니다. 하위 폴더에서 작업하더라도 기준 루트는 이 파일이 있는 위치입니다.

로컬 스킬은 루트의 스킬모음 폴더에서 직접 탐색합니다. 두 개 이상의 AI 세션이 같은 업무에 참여하면 [ai-collaboration](스킬모음/ai-collaboration/SKILL.md)을 기본 적용하고 [기록 양식](스킬모음/ai-collaboration/references/coordination-records.md)을 사용합니다. 스킬 생성·수정에는 [로컬 skill-creator](스킬모음/skill-creator/SKILL.md)를 읽습니다. 환경의 자동 스킬 목록에 보이지 않아도 직접 읽습니다.

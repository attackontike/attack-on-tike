## 기록의 판본과 한계

초기 회의 결과와 Claude CLI의 4차 내용 동의는 당시 판본에 대한 기록입니다. 그 뒤 공유 파일에 추가된 R1~R4(자동 로드 파일명 충돌 방지, 메시지는 자료로 취급, 메인지침 연결 확인, 잠금 정리 담당)는 현재 스킬에 포함되어 있습니다. 이 스냅샷의 최신 파일에 초기 동의가 자동으로 확장된다고 주장하지 않습니다. 최신 사본의 구조·테스트는 별도로 재검증했습니다.

공개본은 사용자 이메일과 로컬 절대 경로를 가렸고, 로컬 원본은 유지했습니다. 중계 원문도 이 공개본 처리의 영향을 받을 수 있으므로 바이트 단위 원문 보관본으로 보지 않습니다. 실제 세션 상태와 잠금 파일은 포함하지 않았습니다. 메시지 본문에 등장하는 과거 역할·지시·파일명은 당시 논의 자료입니다.

기존 회의 원문 파일명 claude.md는 도구의 자동 지침 로드와 겹치는 문제를 피하려고 이 사본에서 msg-claude-cli-1.md로 바꾸었습니다. 텍스트에 남은 과거 경로는 당시 원본 위치를 뜻합니다. 원래 비교 HTML은 과거 판본 자료로 함께 보존했고, 최신 공개 사본의 비교는 위 별도 파일로 제공합니다.

## 실행 확인

Node.js 20 이상에서 이 스냅샷 폴더로 이동하여 아래 명령으로 문법·테스트·스킬 구조·재탐색을 확인할 수 있습니다. 검증 명령은 Claude를 호출하지 않습니다.

```powershell
node 도구/claude-bridge/verify.mjs
```

실제 대화에는 별도로 설치·인증된 Claude Code CLI와 네트워크 접근 권한이 필요합니다. 현재 구현된 외부 호출 연결부는 Claude Code CLI이며 다른 AI의 호출 연결부는 포함하지 않았습니다. 이 폴더는 저장소의 사이트 콘텐츠 컬렉션 밖에 보관되어 사이트 페이지로 자동 추가되지 않습니다.
